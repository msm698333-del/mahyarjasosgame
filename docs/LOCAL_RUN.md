# اجرای محلی

## پیش‌نیازها

- Node.js **۲۲.۵ یا بالاتر** (برای `node:sqlite`) — بررسی: `node -v`
  (یا Bun نسخه ۱.۱ به بالا — لایهٔ دیتابیس به‌صورت خودکار از `bun:sqlite` استفاده می‌کند)
- بدون نیاز به هیچ دیتابیس خارجی یا سرویس دیگر

## اجرا

```bash
cd spy-game
npm install
npm start
```

سرور روی `http://localhost:3003` بالا می‌آید و **فرانت‌اند را هم خودش ارائه می‌کند** — کافی است در مرورگر باز کنید.

برای تغییر پورت:

```bash
PORT=4000 npm start
```

## تست چندنفره روی یک کامپیوتر

- چند تب/پنجرهٔ مرورگر (یا یک تب عادی + یک تب ناشناس) باز کنید؛ هر تب یک هویت جدا می‌گیرد.
- یا شبیه‌ساز خودکار را اجرا کنید:

```bash
npm run sim      # ۸ ربات یک بازی کامل می‌کنند + تست امنیت + دوز (نیاز به سرور در حال اجرا)
```

- درایور ربات برای تست دستی:

```bash
node scripts/room_driver.js          # لابی می‌سازد، کد را چاپ می‌کند و بازی را می‌رانجاتد
node scripts/room_driver.js "" 2 0 30000   # ۲ ربات + ۲ جای خالی، شروع بعد از ۳۰ ثانیه
```

(بازیکن انسانی با کد چاپ‌شده از صفحهٔ «ورود با کد لابی» وارد می‌شود.)

## تنظیمات اختیاری محلی

`.env.example` را ببینید؛ برای اجرای محلی همه‌چیز پیش‌فرض خوب دارد. مهم‌ترین‌ها:

```bash
PORT=3003
SECRET=change-me-to-a-long-random-string
START_COINS=60
FREE_ENTRIES=4
```

## بازیابی پس از ری‌استارت

اتاق‌های فعال در دیتابیس (`data/spy.db`) ذخیره می‌شوند؛ اگر سرور وسط بازی ری‌استارت شود، اتاق‌ها بازیابی می‌شوند و بازیکنان با اتصال مجدد دقیقاً از همان نقطه ادامه می‌دهند (تایمرها بر اساس مهلت ذخیره‌شده از سر گرفته می‌شوند).

## پاک‌کردن داده‌های محلی

```bash
rm -rf data        # دیتابیس ساخته می‌شود
```

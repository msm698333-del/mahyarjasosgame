# سرویس‌های موردنیاز — توضیح دقیق

## چه سرویس‌هایی لازم است؟

| نقش | سرویس | ضرورت | توضیح |
|---|---|---|---|
| میزبانی فرانت‌اند استاتیک | **Tiiny Host** | لازم | فایل‌های `client/` (۱۳ صفحه + دارایی‌ها). هیچ قابلیت سروری لازم ندارد. |
| اجرای بک‌اند Node.js | **Render / Railway / Fly.io / VPS** | لازم | Express + Socket.IO + SQLite در یک فرآیند. باید WebSocket پشتیبانی کند (همهٔ موارد نامبرده پشتیبانی می‌کنند). |
| دیسک پایدار | Disk در Render/Railway/Fly | قویاً توصیه‌شده | برای ماندگاری فایل SQLite (هویت، سکه، تاریخچه). بدون دیسک، با هر ری‌استارت داده‌ها صفر می‌شود. |
| HTTPS | خودکار روی Tiiny و سرویس‌های ابری | لازم | برای کوکی امن و اتصال امن. |
| دامنه | اختیاری | اختیاری | Tiiny زیردامنهٔ رایگان می‌دهد؛ دامنهٔ اختصاصی هم قابل اتصال است. |
| CDN / Redis / Postgres / Nginx | — | لازم نیست | بار این بازی روی یک فرآیند Node + SQLite به‌راحتی قابل‌تحمل است؛ مسیر توسعه در پایین آمده است. |

## چرا بک‌اند جدا؟

Tiiny Host فقط فایل استاتیک سرو می‌کند (بدون Node/WebSocket/دیتابیس). پس:

1. بک‌اند باید روی سرویسی اجرا شود که Node.js و WebSocket دارد.
2. فرانت و بک در دو دامنهٔ متفاوت قرار می‌گیرند؛ بنابراین:
   - سرور CORS را با echo مبدا + credentials پیکربندی کرده است (`ALLOWED_ORIGIN` اختیاری برای سخت‌گیری).
   - هویت علاوه بر کوکی امن، با توکن امضاشدهٔ HMAC پشتیبانی می‌شود (چون کوکی ثالث در Safari/Chrome محدود است).
3. آدرس بک‌اند فقط در یک فایل تنظیم می‌شود: `client/config.js → BACKEND_URL`.

## حالت «هم‌دامنه» (بدون Tiiny)

اگر نخواهید از Tiiny استفاده کنید، همین پروژه به‌صورت یکپارچه هم کار می‌کند: سرور فرانت را از پوشهٔ `client` ارائه می‌دهد و همه‌چیز هم‌دامنه است (کوکی HttpOnly مستقیم کار می‌کند). برای این حالت فقط `node server/index.js` کافی است.

## مسیر رشد (وقتی بازی بزرگ شد)

- **دیتابیس**: `server/db.js` تنها نقطهٔ دسترسی داده است؛ تعویض به Postgres فقط تغییر همین فایل است (ساختار جداول: `docs/schema.sql`).
- **مقیاس افقی**: Socket.IO نیاز به adapter دارد (`@socket.io/redis-adapter`) و اتاق‌ها باید به Redis منتقل شوند؛ فعلاً اتاق‌ها در حافظه + snapshot در SQLite هستند.
- **مانیتورینگ**: `/api/health` برای health-check آماده است (uptime، تعداد اتاق‌ها، نوع درایور دیتابیس).

## هزینهٔ تقریبی

- Tiiny Host: پلن رایگان (با محدودیت حجم/بازدید) تا پلن‌های کم‌هزینه — حجم کل فرانت ~۳MB است.
- Render/Railway: پلن رایگان برای شروع؛ برای بدون-sleep بودن و دیسک پایدار، پلن‌های ~۵–۷ دلار در ماه.

# استقرار بازی جاسوس روی Tiiny Host (+ بک‌اند ابری)

## واقعیت‌های Tiiny Host (بررسی‌شده)

Tiiny Host **فقط میزبانی فایل استاتیک** است:

- پشتیبانی از Node.js، WebSocket، Socket.IO، API سمت سرور یا دیتابیس **ندارد**.
- فرمت‌های پذیرفته‌شده: zip / pdf و فایل‌های استاتیک (HTML/CSS/JS/تصویر/صدا).
- سایت استاتیک شما در دامنه‌ای جدا از بک‌اند سرویس می‌شود (مثل `yoursite.tiiny.site`).

بنابراین معماری پروژه از روز اول برای این محدودیت طراحی شده است:

- **فرانت‌اند استاتیک** → Tiiny Host
- **بک‌اند Node.js (Express + Socket.IO + SQLite)** → یک سرویس ابری رایگان/ارزان با پشتیبانی WebSocket
- فرانت با تنظیم `BACKEND_URL` به بک‌اند وصل می‌شود (CORS و کوکی بین‌دامنه‌ای از قبل مدیریت شده است).

هیچ قابلیتی از Tiiny فرض نشده که پشتیبانی نمی‌کند؛ ارتباط بلادرنگ کاملاً از طریق بک‌اند مستقل انجام می‌شود.

## گام ۱ — استقرار بک‌اند روی Render (رایگان)

۱. حساب در [render.com](https://render.com) بسازید → **New → Web Service**.
۲. کد پروژه (پوشهٔ `spy-game`) را در یک ریپازیتوری Git بگذارید و وصل کنید
   (یا از «Deploy from local» / CLI استفاده کنید).
۳. تنظیمات:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `node server/index.js`
   - **Environment Variable**:
     - `SECRET` = یک رشتهٔ تصادفی بلند (تولید: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`)
     - `PORT` = خالی بگذارید (Render خودش تزریق می‌کند و سرور از env می‌خواند)
     - `ALLOWED_ORIGIN` = خالی (پذیرش همهٔ مبداها؛ سخت‌گیرانه‌تر: دامنهٔ Tiiny خود)
   - **Disk (مهم)**: یک Persistent Disk متصل کنید (مثلاً mount path `/var/data`) و متغیر `DB_PATH=/var/data/spy.db` بگذارید؛ وگرنه با هر ری‌استارت، دیتابیس پاک می‌شود.
۴. پس از deploy، آدرس بک‌اند مثل `https://spy-backend-xxxx.onrender.com` را داشته باشید.
5. تست: `https://<آدرس-بک>/api/health` باید `{"ok":true,...}` بدهد.

> جایگزین‌ها: Railway (با Volume)، Fly.io (با Volume)، یک VPS کوچک با PM2.
> روی Railway/Fly هم فقط دو چیز مهم است: اجرای `node server/index.js` + دیسک پایدار برای SQLite.

## گام ۲ — تنظیم فرانت‌اند

فایل `client/config.js` را باز کنید:

```js
window.SPY_CONFIG = {
  MODE: 'tiiny',                                   // اجبار حالت دامنهٔ جدا
  BACKEND_URL: 'https://spy-backend-xxxx.onrender.com', // آدرس گام ۱
  GATEWAY_PORT: 3003,
};
```

نکته: اگر `MODE: 'auto'` بگذارید هم کار می‌کند (چون `BACKEND_URL` پر است به حالت tiiny می‌رود).

## گام ۳ — آپلود روی Tiiny Host

۱. محتویات پوشهٔ `client/` را zip کنید (فایل‌های zip آماده هم در بستهٔ تحویل هست: `spy-tiiny-client.zip`).
۲. در [tiiny.host](https://tiiny.host) آپلود کنید.
۳. اگر پلن شما اجازهٔ تنظیم می‌دهد، HTTPS را فعال بگذارید (پیش‌فرض فعال است).

## نکته‌های مهم بین‌دامنه‌ای (صادقانه و دقیق)

- **کوکی بین‌دامنه‌ای**: مرورگرهای مدرن (به‌خصوص Safari و نسخه‌های جدید Chrome) کوکی ثالث را محدود/مسدود می‌کنند. برای همین، هویت علاوه بر کوکی امن `HttpOnly` با یک **توکن امضاشده (HMAC)** هم پشتیبانی می‌شود که کلاینت در localStorage نگه می‌دارد و در هدر `Authorization: Bearer` می‌فرستد. این توکن قابل‌جعل نیست (امضای سرور دارد) و همان سطح امنیت کوکی را برای «عدم جعل هویت/موجودی» فراهم می‌کند. نتیجه: ورود مجدد کاربر روی Tiین با همان هویت قبلی کار می‌کند.
- **Socket.IO بین‌دامنه‌ای**: کانکشن WebSocket محدودیت SameSite ندارد؛ فقط CORS سرور باید مبدا را بپذیرد (پیش‌فرض سرور: echo همهٔ مبداها + credentials).
- **HTTPS الزامی است** (هم Tiiny و هم بک ابری HTTPS دارند) تا `SameSite=None; Secure` و میکروفون/کلیپ‌بورد درست کار کنند.
- **دیتابیس**: SQLite روی دیسک پایدار کافی است؛ اگر روزی مقیاس گرفتید، ساختار جداول در `docs/schema.sql` است و لایهٔ `db.js` تنها نقطهٔ تعویض درایور (مثلاً Postgres) است.

## چک‌لیست پس از انتشار

- [ ] `/api/health` بک‌اند جواب می‌دهد.
- [ ] ثبت نام در Tiiny انجام می‌شود و صفحهٔ اصلی می‌آید.
- [ ] ساخت لابی از یک گوشی و ورود با کد از گوشی دوم کار می‌کند.
- [ ] صداها پخش می‌شوند (اولین لمس لازم است — سیاست مرورگرها).
- [ ] دیسک پایدار بک‌اند متصل است (سکه‌ها بعد از ری‌استارت حفظ شوند).

## محدودیت‌ها و راهکارها (شفاف)

| محدودیت | راهکار پیاده‌شده |
|---|---|
| Tiiny فقط استاتیک است | بک‌اند مستقل روی Render/Railway؛ فرانت فقط fetch/io |
| کوکی ثالث در Safari/Chrome مسدود می‌شود | توکن Bearer امضاشده پشتیبان کوکی |
| استروژ تایمر روی ارزان‌ترین پلن‌ها (sleep) | `/api/health` + اتصال مجدد خودکار سوکت؛ برای ۲۴/۷، پلن بدون sleep بگیرید |
| فایل‌های صوتی WAV حجم دارند | لوپ‌های ۱۲ ثانیه‌ای با کیفیت مناسب (~۱.۹MB کل) |
| SQLite + چند نمونه سرور | تک‌نمونه نگه دارید؛ برای مقیاس، لایه db.js را به Postgres سوئیچ کنید |

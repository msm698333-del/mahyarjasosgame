## ۱. خلاصهٔ پروژه

بازی آنلاین چندنفرهٔ اجتماعی-استنتاجی «جاسوس» (سبک Spyfall) با معماری کاملاً ابری روی **Cloudflare Workers**:

- **بک‌اند:** Cloudflare Worker + Durable Object (`GameRoomDO`) برای هر لابی — WebSocket Hibernation، DO Storage به‌عنوان منبع حقیقت، DO Alarm برای تایمرها
- **فرانت:** React 19 + TypeScript + Tailwind 4 + Vite — رابط فارسی راست‌چین با تم تاریک کارآگاهی، سرو‌شده توسط همان Worker
- **صوت:** WebRTC mesh مستقیم بین مرورگرها (P2P)؛ سیگنالینگ از WS لابی؛ بدون ذخیرهٔ صدا
- **دیتابیس (اختیاری):** D1 برای تاریخچهٔ بازی‌ها — بازی بدون آن هم کامل است

## ۲. ساختار و فایل‌ها (۵٬۲۱۸ خط کد اصلی)

| مسیر | محتوا |
|---|---|
| `worker/index.ts` | مسیریابی REST، ارتقای WebSocket، سرو SPA، `/api/ice` |
| `worker/do.ts` | Durable Object — اتصال‌ها، Hibernation، Alarm، D1 |
| `worker/room.ts` | پروتکل اتاق — اعتبارسنجی پیام‌ها، نرخ‌گذاری |
| `worker/ice.ts` | ساخت ICE از Secrets (بدون اتصال فرضی) |
| `shared/engine.ts` | موتور بازی خالص سمت سرور (منبع حقیقت قوانین) |
| `shared/locations.ts` | ۹ دسته × ~۷۹ مکان × ۸ نقش فارسی |
| `app/` | فرانت React: صفحهٔ ورود، خانه، لابی، افشای نقش، اتاق بازی، رأی‌گیری، حدس جاسوس، نتایج، تنظیمات |
| `tests/` | ۵۹ تست واحد (موتور + پروتکل + تاب‌آوری) |
| `scripts/smoke_e2e_cloudflare.mjs` | تست دود E2E با ۳ کلاینت WebSocket واقعی |
| `docs/DEPLOY_CLOUDFLARE.md` | راهنمای کامل انتشار فارسی |
| `wrangler.jsonc` | پیکربندی انتشار — بدون نیاز به تنظیم |

## ۵. موارد باقی‌مانده برای شما (همه اختیاری)

1. **انتشار روی Cloudflare** (۵ دقیقه): طبق `docs/DEPLOY_CLOUDFLARE.md` — یا اتصال این ریپو در داشبورد، یا `npx wrangler login` و `npm run deploy` روی کامپیوتر خودتان.
   آدرس پس از انتشار: `https://mahyarjasos.<نام-اکانت>.workers.dev`
2. **D1 (اختیاری):** اگر تاریخچهٔ بازی‌ها را می‌خواهید، بلوک کامنت‌شدهٔ `d1_databases` در `wrangler.jsonc` را فعال کنید.
3. **TURN (اختیاری):** برای شبکه‌های سخت‌گیر سه Secret بگذارید: `TURN_URLS`، `TURN_USERNAME`، `TURN_CREDENTIAL` (مثلاً از Cloudflare Calls TURN). بدون آن، STUN عمومی فعال است که در اکثر شبکه‌ها کافی است.
4. **تست صوت دو-مرورگری پس از انتشار:** در محیط واقعی با دو دستگاه/مرورگر، صوت، استیکر و رأی‌گیری را امتحان کنید — منطق توسط تست دود پوشش داده شده ولی کیفیت صوت P2P به شبکهٔ شما وابسته است.

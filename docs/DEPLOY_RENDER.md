# استقرار بازی SPY روی Render.com (از طریق GitHub)

راهنمای گام‌به‌گام انتشار بازی روی Render.com. سطح دشواری: **مقدماتی** — برای این مسیر به نصب هیچ برنامه‌ای روی کامپیوتر نیاز نیست و همه‌چیز از مرورگر انجام می‌شود.

---

## دو راه برای انتشار

| گزینه | روی Render | روی Tiiny Host | نتیجه |
|---|---|---|---|
| **A — همه روی Render (پیشنهادی)** | فرانت + بک‌اند + دیتابیس | — | بازی کامل روی یک آدرس `https://…onrender.com` |
| **B — فرانت Tiiny + بک‌اند Render** | فقط بک‌اند | فرانت استاتیک | فرانت و بک روی دو دامنهٔ جدا |

> در گزینهٔ A اصلاً به Tiiny Host نیازی نیست؛ سرور ما فرانت را هم ارائه می‌دهد (`SERVE_CLIENT`). برای شروع، گزینهٔ A ساده‌ترین است.

---

## ۱) ساخت حساب GitHub و آپلود پروژه

### ۱-۱) ساخت حساب
1. به [github.com](https://github.com) بروید → **Sign up**
2. ایمیل و رمز عبور بدهید و ایمیل تأیید را تأیید کنید.

> نکتهٔ دسترسی: در برخی شبکه‌ها دسترسی به GitHub و Render ممکن است محدود باشد؛ در صورت خطا، تغییر DNS یا IP معمولاً مشکل را حل می‌کند.

### ۱-۲) ساخت ریپازیتوری
1. بعد از ورود، بالای صفحه روی **+** → **New repository** کلیک کنید.
2. **Repository name**: `spy-game`
3. **Public** یا **Private** (هر دو با Render کار می‌کند؛ Private هم رایگان است).
4. هیچ تیک «Add a README» نزنید — ریپو باید خالی باشد.
5. **Create repository**.

### ۱-۳) آپلود فایل‌ها — روش وب (بدون نصب برنامه)
1. در صفحهٔ ریپوی خالی، روی لینک **«uploading an existing file»** کلیک کنید.
2. فایل‌های پروژه را از فایل‌منیجر درگ کنید و در صفحه رها کنید.
   - اگر فایل `spy-game-full.zip` را دارید، اول آن را **Extract** کنید و **محتویات داخلش** را بکشید (خود zip را نه).
   - پوشهٔ `spy-game` را نه؛ **فایل‌ها و پوشه‌های داخلش** باید آپلود شوند (`server/`, `client/`, `package.json`, …).
3. این دو پوشه را آپلود **نکنید**:
   - `node_modules/` (وابستگی‌ها را خود Render با `npm install` نصب می‌کند)
   - `data/` (دیتابیس محلی شماست؛ روی سرور از اول ساخته می‌شود)
4. تا پایان بارگذاری صبر کنید (~۱۲۰ فایل، چند ثانیه تا چند دقیقه).
5. پایین صفحه در باکس Commit changes بنویسید: `SPY game v1.0` → دکمهٔ **Commit changes**.

> بعد از آپلود، صفحهٔ ریپو باید این موارد را نشان دهد: `server/` ، `client/` ، `docs/` ، `scripts/` ، `package.json` ، `package-lock.json` ، `render.yaml` ، `.gitignore` ، `README.md`

### ۱-۴) روش خط فرمان (جایگزین حرفه‌ای‌تر)
اگر Git نصب دارید، از داخل پوشهٔ پروژه:

```bash
git init
git add .
git commit -m "SPY game v1.0"
git branch -M main
git remote add origin https://github.com/<USERNAME>/spy-game.git
git push -u origin main
```

## ۲) ساخت حساب Render و اتصال به GitHub

1. به [render.com](https://render.com) بروید → **Get Started for Free**.
2. گزینهٔ **Sign in with GitHub** را انتخاب کنید (نه ایمیل — تا دسترسی ریپو داده شود).
3. پنجرهٔ مجوز GitHub: **Authorize Render**؛ می‌توانید «All repositories» یا «Only select repositories → spy-game» را انتخاب کنید.

> پلن رایگان Render کارت بانکی نمی‌خواهد؛ برای ارتقای بعدی به Starter کارت بین‌المللی لازم است.

---

## ۳) ساخت Web Service

1. در داشبورد Render: **New +** → **Web Service**.
2. ریپوی `spy-game` را انتخاب کنید → **Connect**.
3. اگر `render.yaml` در ریپو باشد، Render آن را به‌عنوان **Blueprint** می‌شناسد و تنظیمات را خودش پر می‌کند — فقط **Apply** / **Create** بزنید.
4. در غیر این صورت فرم را دستی پر کنید:

| فیلد | مقدار |
|---|---|
| Name | `spy-game` (آدرس نهایی: `https://spy-game-xxxx.onrender.com`) |
| Language / Runtime | `Node` |
| Branch | `main` |
| Region | `Frankfurt (EU Central)` — نزدیک‌ترین به ایران |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Health Check Path | `/api/health` |
| Instance Type | `Free` |

---

## ۴) متغیرهای محیطی (Environment Variables)

در بخش **Environment** (همان فرم اولیه یا بعداً از تب Environment):

| کلید | مقدار | ضروری؟ | توضیح |
|---|---|---|---|
| `NODE_VERSION` | `22.17.0` | **بله — حیاتی** | دیتابیس از ماژول داخلی `node:sqlite` استفاده می‌کند که از Node **۲۲.۱۳** به بالا بدون فلگ فعال است؛ نسخهٔ کمتر = کرش موقع اجرا |
| `SECRET` | رشتهٔ تصادفی بلند (یا Generate) | بله | کلید امضای توکن هویت. بعد از انتشار **تغییرش ندهید** وگرنه همهٔ کاربران لاگ‌اوت می‌شوند |
| `SERVE_CLIENT` | `1` | اختیاری | پیش‌فرض فعال است؛ فرانت از همین سرویس سرو می‌شود (گزینهٔ A) |
| `ALLOWED_ORIGIN` | خالی | اختیاری | خالی = همهٔ دامنه‌ها پذیرفته می‌شوند (CORS بازتابی). برای قفل‌کردن: دامنهٔ فرانت (مثلاً دامنهٔ Tiiny) |

> ⚠️ مقدار `PORT` را دستی ست نکنید — Render خودش تزریق می‌کند و سرور از همان استفاده می‌کند.

---

## ۵) Deploy و تست سلامت

1. دکمهٔ **Create Web Service / Deploy** را بزنید.
2. در تب **Events / Logs** ببینید: اول `npm install` اجرا می‌شود، بعد لاگ سرور (`listening …`) و وضعیت به **Live** تغییر می‌کند (اولین deploy معمولاً ۲ تا ۵ دقیقه).
3. سه تست:

| تست | آدرس | نتیجهٔ موردانتظار |
|---|---|---|
| سلامت API | `https://<YOUR-APP>.onrender.com/api/health` | JSON حاوی `ok:true` و نام درایور دیتابیس |
| فرانت | باز کردن خودِ `https://<YOUR-APP>.onrender.com` | صفحهٔ ورود بازی (ورود با نام) |
| دیتابیس | ثبت‌نام با یک نام آزمایشی | رفتن به صفحهٔ خانه با **۶۰ سکه** |

---

## ۶) تست چندنفرهٔ واقعی

1. روی دو مرورگر یا دو گوشی، با **دو نام متفاوت** وارد شوید.
2. یکی: **ساخت لابی** (تعداد اسلات‌ها و هزینهٔ ورود) → کد ۶ رقمی نمایش داده می‌شود.
3. دیگری: **عضویت با کد** → به لابی اضافه می‌شود.
4. میزبان بازی را شروع کند؛ اگر جریان سؤال‌وپاسخ، استیکر و رأی‌گیری روی هر دو دستگاه **بلادرنگ** جابه‌جا شد، اتصال WebSocket (مسیر `/spy-ws`) سالم است.

## ۷) (اختیاری) دیسک پایدار برای SQLite — پلن پولی

**محدودیت مهم پلن رایگان:** فایل دیتابیس روی دیسک موقت ذخیره می‌شود و با هر redeploy یا ری‌استارت سرویس **پاک می‌شود** (بازیکنان، سکه‌ها و تاریخچه ریست می‌شوند). برای ماندگاری:

1. از تب **Settings** پلن را به **Starter** ارتقا دهید (~۷ دلار در ماه؛ بدون خواب‌شدن سرویس).
2. تب **Disks** → **Add Disk**: Name=`spy-data` ، Mount Path=`/data` ، Size=`1GB`.
3. در Environment اضافه کنید: `DB_PATH = /data/spy.db`
4. **Save & Deploy**.

یا در `render.yaml` خطوط `disk:` و `DB_PATH` را از کامنت خارج کنید و دوباره push کنید.

## ۸) گزینهٔ B — فرانت روی Tiiny Host + بک‌اند روی Render

اگر می‌خواهید فرانت جدا روی Tiiny باشد:

1. بک‌اند را طبق بخش‌های ۱ تا ۵ روی Render اجرا کنید و آدرسش را بردارید:
   `https://spy-game-xxxx.onrender.com`
2. فایل `client/config.js` را باز کنید و این‌طور تنظیم کنید:

```js
window.SPY_CONFIG = {
  MODE: 'tiiny',
  BACKEND_URL: 'https://spy-game-xxxx.onrender.com',
  GATEWAY_PORT: 3003,
};
```

   (می‌توانید همین فایل را مستقیم در وب GitHub با آیکون مداد ویرایش و Commit کنید.)
3. **محتویات** پوشهٔ `client/` را zip کنید — دقت کنید `index.html` باید در **ریشهٔ** zip باشد، نه داخل پوشه.
   - در ویندوز: همهٔ فایل‌های داخل `client/` را انتخاب کنید → راست‌کلیک → Send to → Compressed (zipped) folder
   - یا فایل آمادهٔ `spy-tiiny-client.zip` را Extract کنید، فقط خط `BACKEND_URL` را ویرایش کنید و دوباره zip کنید.
4. در [tiiny.host](https://tiiny.host) حساب بسازید → zip را آپلود → **Publish**.
5. آدرس Tiiny را باز کنید و با یک نام وارد شوید؛ اگر ۶۰ سکه دیدید، اتصال به Render برقرار است.

راهنمای مفصل‌تر Tiiny: `docs/DEPLOY_TIINY_HOST.md`

## ۹) به‌روزرسانی نسخه‌های بعدی

- هر **push** به شاخهٔ `main` → Render **خودکار** deploy می‌کند.
- از وب GitHub هم می‌توانید: فایل را باز کنید → آیکون ✏️ (Edit) → تغییر → **Commit changes** → deploy خودکار.
- ⚠️ روی پلن رایگان (بدون دیسک) هر deploy = ریست دیتابیس.

## ۱۰) هزینه‌ها و محدودیت‌ها

| موضوع | پلن Free | پلن Starter (~$7/ماه) |
|---|---|---|
| خواب‌شدن بعد از ۱۵ دقیقه بی‌کاری | بله — اولین بازدید بعد از خواب ~۵۰ ثانیه طول می‌کشد | خیر |
| ماندگاری فایل (SQLite) | خیر — با هر deploy پاک می‌شود | بله — با دیسک |
| RAM | ۵۱۲MB | ۵۱۲MB |
| WebSocket | پشتیبانی می‌شود | پشتیبانی می‌شود |
| کارت بانکی | لازم ندارد | کارت بین‌المللی لازم است |

> برای تست و بازی با دوستان، پلن Free کاملاً کافی است. برای بازی عمومی و ماندگاری سکه‌ها، Starter + Disk توصیه می‌شود.

## عیب‌یابی

| نشانه | علت احتمالی | راه‌حل |
|---|---|---|
| Deploy fail با خطای sqlite یا `No such built-in module: node:sqlite` | `NODE_VERSION` ست نشده یا کمتر از ۲۲.۱۳ است | `NODE_VERSION=22.17.0` را در Environment اضافه و Deploy کنید |
| صفحهٔ بازی باز می‌شود ولی «خطا در ارتباط با سرور» می‌بینید | API/WebSocket وصل نیست | لاگ‌های Render را ببینید؛ مسیر WS همان دامنه با پیشوند `/spy-ws` است؛ `BACKEND_URL` را چک کنید |
| اولین باز کردن خیلی طول می‌کشد | سرویس رایگان خواب بوده | ~۵۰ ثانیه صبر کنید؛ بازدید بعدی سریع است |
| خطای CORS در کنسول مرورگر | `ALLOWED_ORIGIN` قفل شده | خالی بگذارید یا دامنهٔ فرانت را داخلش بنویسید |
| بعد از deploy همهٔ بازیکن‌ها و سکه‌ها پاک شدند | پلن بدون دیسک | بخش ۷ (Starter + Disk) |
| کاربران قبلی 401 می‌گیرند | `SECRET` تغییر کرده | `SECRET` را ثابت نگه دارید |
| Build fail: `Cannot find module './server/…'` | آپلود ناقص | مطمئن شوید کل پوشهٔ `server/` و `package.json` در ریپو هستند |
| فایل‌ها آپلود نمی‌شوند از مرورگر | مرورگر موبایل یا اتصال ناپایدار | مرورگر دسکتاپ استفاده کنید یا روش خط فرمان (بخش ۱-۴) |

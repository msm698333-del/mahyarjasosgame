# بازی آنلاین جاسوس (SPY)

بازی چندنفرهٔ بلادرنگ «جاسوس» — شهروندها کلمهٔ مخفی مشترک می‌گیرند و جاسوس باید خودش را پنهان کند و کلمه را حدس بزند. سؤال آزاد، چالش ۱۵ ثانیه‌ای، رأی‌گیری محرمانه، شب جاسوس، اقتصاد سکه، فروشگاه آواتار و بازی دوز.

## معماری در یک نگاه

```
┌────────────────────────┐        ┌──────────────────────────────┐
│  فرانت‌اند (استاتیک)     │  HTTPS │  بک‌اند Node.js (یک سرویس)     │
│  HTML/CSS/JS خالص       │◄──────►│  Express (REST)              │
│  ۱۳ صفحه + دارایی‌ها     │  WS    │  Socket.IO (بلادرنگ)          │
│  روی Tiiny Host         │  /spy-ws│  SQLite (بازیکن، اتاق، سکه…)  │
└────────────────────────┘        └──────────────────────────────┘
     client/                            server/
```

- **فرانت‌اند**: HTML/CSS/JavaScript خالص، RTL، موبایل‌فرست، تم تاریک شیشه‌ای، بدون هیچ فریم‌ورک — دقیقاً سازگار با میزبانی استاتیک Tiiny Host.
- **بک‌اند**: Node.js + Express + Socket.IO روی یک سرویس مستقل (Tiiny فقط استاتیک میزبانی می‌کند؛ پس بک‌اند باید روی سرویسی مثل Render/Railway اجرا شود — راهنمای کامل در `docs/DEPLOY_TIINY_HOST.md`).
- **دیتابیس**: SQLite (فایل) با درایور خودکار `node:sqlite` یا `bun:sqlite`. همهٔ داده‌های مهم (هویت، سکه، اتاق‌ها، نتایج) سمت سرور ذخیره می‌شوند؛ از LocalStorage فقط برای تنظیمات ظاهری/صوتی و «توکن امضاشده» استفاده می‌شود (هیچ داده اقتصادی قابل‌جعل نیست).
- **بلادرنگ**: Socket.IO با مسیر سفارشی `/spy-ws`؛ حالت‌های اتصال: هم‌دامنه (self-host)، Gateway پلتفرم، و دامنهٔ جدا (Tiiny + بک ابری).
- **ویس زنده**: گفتگوی صوتی داخل لابی و مسابقه با WebRTC — صدا مستقیم بین بازیکنان رد و بدل می‌شود و از سرور عبور نمی‌کند (سرور فقط اتصال‌ها را راه‌اندازی می‌کند). میکروفون قابل‌قطع، نشانگر «در حال صحبت» روی کارت بازیکن‌ها، و بازگشت خودکار پس از قطع اتصال.

## اجرای محلی (خلاصه)

```bash
cd spy-game
npm install
npm start          # http://localhost:3003  (سرور، فرانت را هم ارائه می‌کند)
```

نیازمندی: Node.js نسخهٔ ۲۲.۱۳ به بالا (برای `node:sqlite` بدون فلگ) یا Bun. راهنمای کامل: `docs/LOCAL_RUN.md`.

## استقرار روی Render.com (خلاصه — پیشنهادی)

سریع‌ترین راه انتشار **کل بازی** (فرانت + بک‌اند + دیتابیس) روی یک آدرس واحد:

1. محتویات پروژه را در یک ریپوی GitHub آپلود کنید (بدون `node_modules/` و `data/`).
2. render.com → New + → Web Service → انتخاب ریپو (یا Blueprint با `render.yaml`).
3. متغیرهای محیطی: `NODE_VERSION=22.17.0` (حیاتی — `node:sqlite` از ۲۲.۱۳ به بالا) و `SECRET` (رشتهٔ تصادفی).
4. Health Check Path: `/api/health` — بازی کامل روی `https://<your-app>.onrender.com` بالا می‌آید.

راهنمای گام‌به‌گام کامل: `docs/DEPLOY_RENDER.md`

## استقرار روی Tiiny Host (خلاصه)

1. بک‌اند را روی Render/Railway اجرا کنید (Web Service + دیسک پایدار برای SQLite).
2. در `client/config.js` مقدار `BACKEND_URL` را با آدرس بک‌اند پر کنید.
3. محتویات پوشهٔ `client/` را zip کنید و در tiiny.host آپلود کنید.

راهنمای گام‌به‌گام: `docs/DEPLOY_TIINY_HOST.md` · سرویس‌های موردنیاز: `docs/SERVICES.md`

## قوانین بازی (خلاصه)

| تعداد بازیکن | جاسوس |
|---|---|
| ۴ تا ۹ | ۱ |
| ۱۰ و ۱۱ | ۲ |
| ۱۲ | ۳ |

(جدول در `server/config.js` قابل تنظیم است؛ برای تعدادهای دیگر مقدار منطقی `floor(n/5)` اعمال می‌شود.)

- ترم‌های روز اول = **تعداد بازیکنان + ۲** (۱۰ بازیکن = ۱۲ ترم). روزهای بعدی به تعداد زنده‌ها.
- جریان هر ترم: پرسشگر هدف و سؤال را انتخاب می‌کند → پاسخ‌دهنده جواب می‌دهد → پاسخ‌دهنده **۱۵ ثانیه** فرصت دارد چالش بعدی را انتخاب کند؛ اتمام زمان = مدیریت خودکار سیستم.
- پس از ترم‌ها: رأی‌گیری محرمانه (قابل‌تغییر تا پایان) → بیشترین رأی حذف می‌شود → تساوی: رأی‌گیری مجدد بین متساوی‌ها → تساوی دوباره: قرعه.
- جاسوسِ حذف‌شده یک فرصت حدس کلمه دارد؛ حدس درست = برد جاسوس‌ها.
- **شات جاسوس (نسخه ۱.۱):** فقط در سناریوهای **۶ نفره یا بالاتر**، بعد از رأی‌گیری اگر جاسوس حذف شود، ۱۲ ثانیه فرصت دارد یک بازیکن زنده را «شات» کند (اختیاری؛ او هم حذف می‌شود). در سناریوی زیر ۶ نفر شات وجود ندارد. بعد از شات، فرصت حدس کلمه همچنان برقرار است.
- **اعلام پایان بازی (نسخه ۱.۱):** جاسوسِ زنده در روز یا رأی‌گیری می‌تواند «پایان بازی: کلمه را می‌دانم!» را بزند؛ اگر کلمه را **دقیق و کامل** بنویسد جاسوس‌ها برنده‌اند، اگر حتی یک حرف اشتباه باشد فوراً حذف می‌شود.
- **حدس دقیق (نسخه ۱.۱):** مقایسهٔ حدس کاملاً دقیق است — بازی هیچ راهنمایی نمی‌دهد و ورودی بدون خودکارمکمل/غلط‌گیر است؛ حتی یک حرف اشتباه یعنی حدس اشتباه (فقط فاصله‌های اضافی و ی/ک عربی↔فارسی بخشیده می‌شود).
- **اتاق آزمایشی (نسخه ۱.۱):** از «بخش تست» در صفحهٔ اصلی؛ بازی ۲ نفره، ورود رایگان، بدون اثر روی سکه/آمار/تاریخچه — برای تست ویس و بازی. بخش تست شامل تست میکروفون (نوار سطح صدا + ضبط ۳ ثانیه‌ای و پخش)، تست همهٔ افکت‌ها و موسیقی‌ها، و راهنمای تست ویس دو نفره است.
- شب: فقط جاسوس‌ها هدف انتخاب می‌کنند (چندجاسوسی: اکثریت، تساوی: قرعه). هر شب دقیقاً یک حذف. برد شهروندها: حذف همهٔ جاسوس‌ها. برد جاسوس‌ها: تساوی تعداد با شهروندها یا حدس درست کلمه.
- استیکرها تصویری، بی‌صدا و بدون معنای استراتژیک؛ هر بازیکن در هر ترم یک استیکر.

## اقتصاد

- شروع: **۶۰ سکه** + **۴ ورود رایگان** لابی.
- پس از اتمام ورودهای رایگان، هزینهٔ ورود هر لابی را میزبان تعیین می‌کند (۰ تا ۱۰۰؛ پیش‌فرض ۱۰) و مبلغ قبل از ورود نمایش داده می‌شود. کمبود سکه → هدایت به بازی دوز.
- برد مسابقه +۵۰، مشارکت +۱۰. پاداش بردهای دوز (آسان ۲ / متوسط ۴ / سخت ۶ / آنلاین ۵) **سقف روزانه** دارد تا فارم‌کردن ممکن نباشد.
- اگر لابی پیش از شروع بازی به هم بخورد، ورود کامل برمی‌گردد.

## امنیت (خلاصه)

- هیچ اعتمادی به کلاینت نیست: همهٔ وضعیت‌ها، تایمرها و اعتبارسنجی‌ها سمت سرور.
- نقش/کلمه فقط به خود بازیکن ارسال می‌شود؛ کانال جاسوس هرگز کلمه را نمی‌بیند (با شبیه‌سازی اثبات شده: بدون هیچ نشتی کلمه به جاسوس تا پایان بازی).
- هویت: شناسهٔ تصادفی + کوکی `HttpOnly` امضاشده با HMAC + توکن Bearer پشتیبان (برای فرانت جدا). موجودی و سکه فقط از طریق سرور تغییر می‌کنند.
- رأی‌ها و انتخاب‌های شب محرمانه‌اند (فقط شمارش منتشر می‌شود).
- محدودیت نرخ درخواست‌ها (روی سوکت و HTTP) + محدود طول متن + ضد رأی تکراری/دو استیکر/عمل خارج از نوبت.

## تنظیمات محیطی

همهٔ اعداد (سکه، هزینه ورود، تایمرها، جدول جاسوس‌ها، پورت، کلید امضا) در `server/config.js` از متغیرهای محیطی خوانده می‌شوند — نمونهٔ کامل در `.env.example`.

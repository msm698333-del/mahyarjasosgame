# بازی جاسوس — نسخهٔ ابری Cloudflare

بازی آنلاین چندنفرهٔ اجتماعی و استنتاجی «جاسوس» (سبک Spyfall) با لابی واقعی، صوت زندهٔ P2P، استیکر، رد کردن نوبت و رابط فارسی راست‌چین.

> **نسخهٔ ۲.۰ — بازنویسی کامل معماری برای Cloudflare.**
> پشتهٔ قبلی (Express + Socket.IO + SQLite روی Render/Tiiny) در پوشه‌های `client/`، `server/`، `docs/` و بخشی از `scripts/` حفظ شده ولی دیگر مسیر اصلی پروژه نیست.

## معماری

```
مرورگر (React 19 + TypeScript + Tailwind 4 + Vite)
   │  REST  /api/lobby        ساخت لابی
   │  WS    /ws?code=XXXX     همهٔ ترافیک بازی (همگام‌سازی state، چت، استیکر، سیگنالینگ)
   ▼
Cloudflare Worker  (worker/index.ts)
   ├── Static Assets  ←  خروجی build فرانت (dist/client) — SPA
   ├── /api/ice       ←  STUN عمومی + TURN اختیاری از Secrets
   └── Durable Object «GameRoomDO»  (worker/do.ts)  — هر لابی = یک نمونه
        ├── WebSocket Hibernation  (اتصال‌ها پس از خواب DO زنده می‌مانند)
        ├── DO Storage             (وضعیت لابی/بازی — منبع حقیقت)
        ├── DO Alarm               (تایمرهای بحث/رأی/حدس + پاکسازی)
        └── D1 (اختیاری)           (تاریخچهٔ بازی‌ها)
صوت زنده: WebRTC mesh بین مرورگرها (P2P) — سیگنالینگ فقط از WS لابی عبور می‌کند؛ صدا ذخیره نمی‌شود.
```

### امنیت
- **هیچ اعتمادی به کلاینت نیست:** همهٔ اعتبارسنجی‌ها (نوبت، سهمیهٔ Skip، رأی، حدس، میزبانی، ظرفیت) در موتور سمت سرور (`shared/engine.ts`) انجام می‌شود.
- نقش و مکان مخفی **هرگز** در state عمومی پخش نمی‌شود؛ فقط با پیام خصوصی `role` به صاحب نقش می‌رسد (با تست خودکار و تست دود اثبات شده).
- هر بازیکن `playerId + token` دارد؛ اتصال مجدد فقط با token معتبر.
- رأی‌ها محرمانه‌اند (فقط شمارش) و در پایان افشا می‌شوند.
- محدودیت نرخ چت (۱.۲ ثانیه) و استیکر (۳ ثانیه) سمت سرور.
- بدون هیچ سیستم لایک/دیسلایک یا واکنش امتیازی.

## اجرای محلی

```bash
npm install
npm run build       # build فرانت به dist/client
npm run dev         # wrangler dev روی http://localhost:8787 (فرانت + بک‌اند + WS + D1 محلی)
npm test            # ۵۹ تست موتور بازی و پروتکل
npm run typecheck   # TypeScript کلاینت + وورکر
node scripts/smoke_e2e_cloudflare.mjs   # تست دود E2E با ۳ کلاینت واقعی (سرور باید روشن باشد)
```

## استقرار روی Cloudflare

1. **D1 (اختیاری ولی توصیه‌شده — تاریخچهٔ بازی‌ها):**
   ```bash
   npx wrangler d1 create spy-game-db
   npx wrangler d1 execute spy-game-db --remote --file migrations/0001_init.sql
   ```
   `database_id` خروجی را در `wrangler.jsonc` جای `SET_D1_ID` بگذارید.
   اگر D1 را نمی‌خواهید، بلوک `d1_databases` را از `wrangler.jsonc` حذف کنید — بازی بدون آن کامل است.

2. **TURN (اختیاری — برای شبکه‌های سخت‌گیر):**
   ```bash
   npx wrangler secret put TURN_URLS       # مثل: turn:turn.cloudflare.com:3478?transport=udp
   npx wrangler secret put TURN_USERNAME
   npx wrangler secret put TURN_CREDENTIAL
   ```
   بدون این Secrets فقط STUN فعال است که در اکثر شبکه‌ها کافی است. (برای TURN واقعی می‌توانید از Cloudflare Calls TURN استفاده کنید.) هیچ اتصال فرضی در کد وجود ندارد.

3. **انتشار:**
   ```bash
   npm run deploy        # = vite build + wrangler deploy
   ```
   یا اتصال ریپو به Cloudflare Dashboard (Workers & Pages → Create → Connect to Git) با دستور build `npm run build` و خروجی پیش‌فرض wrangler.

## قوانین بازی

- لابی با کد ۴ حرفی؛ میزبان شروع می‌کند (حداقل ۳ بازیکن متصل).
- مکان مخفی تصادفی از ۹ دسته (۷۹ مکان، هر مکان ۸ نقش فارسی). همه نقش می‌گیرند؛ **جاسوس فقط دستهٔ مکان را می‌بیند**.
- بحث نوبتی: نوبت‌دار هدف پرسش را انتخاب می‌کند، می‌تواند نوبت را با سهمیهٔ محدود «رد کردن نوبت» رد کند یا «پایان پرسش» بزند؛ سقف هر نوبت و مدت بحث تنظیم‌شدنی است.
- رأی‌گیری محرمانه؛ بیشترین رأی متهم می‌شود؛ تساوی → رأی مجدد بین متساوی‌ها؛ تساوی دوباره → برد جاسوس.
- جاسوسِ متهم‌شده یک فرصت حدس مکان دارد: درست = برد جاسوس، غلط/تمام‌شدن زمان = برد شهروندها.
- قطع و اتصال مجدد با token؛ بازیکن قطع‌شدهٔ طولانی از فاز نقش کنار گذاشته می‌شود تا بازی قفل نشود (۶۰ ثانیه) و در ۹۰ ثانیه دور به‌اجازه شروع می‌شود.
- میزبان می‌تواند بازیکن متخلف را حذف کند، صدایش را اجباری قطع کند؛ همه می‌توانند گزارش دهند و صدای هر بازیکن را برای خود بی‌صدا کنند.

## ساختار

```
├── worker/            Worker + Durable Object + پروتکل + ICE
├── shared/            موتور بازی خالص + تایپ‌ها + بانک مکان‌ها (مشترک کلاینت/سرور)
├── app/               فرانت React (صفحات، کامپوننت‌ها، WebRTC، استیکر، آواتار)
├── tests/             تست‌های واحد موتور و پروتکل (vitest)
├── migrations/        SQL دیتابیس D1
├── public/            فایل‌های استاتیک ثابت (favicon)
├── scripts/           تست دود E2E + اسکریپت‌های قدیمی پشتهٔ قبلی
└── client/, server/, docs/   پشتهٔ قدیمی (Legacy — حفظ‌شده)
```
